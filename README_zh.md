# SPXL / TQQQ 的 200 日均线策略研究（第四版）

[English](README.md) · [论文 PDF](paper/SMA200_Leveraged_ETF_Research_v4.pdf) · [Word](paper/SMA200_Leveraged_ETF_Research_v4.docx) · [审稿逐条答复](REVIEWER_RESPONSE.md) · [复现说明](REPRODUCE_V4.md)

**规则：** 用 SPY 的信号交易 SPXL，用 QQQ 的信号交易 TQQQ。信号 ETF 收盘价不低于 200 日均线的 104% 时，每天加仓 20%，最多加到 100%；收盘价跌破均线的 97% 时全部清仓。收盘出信号，次日开盘成交，每笔成本 10bp；闲置现金按上月 T-bill 利率计息。

**数据：** 四个品种全部来自同一数据源（Yahoo / yfinance，市场成交价，按分红和拆股复权），截至 2026-08-06。数据已经过 NYSE 交易日历校验，并和基金发行商的公开数据做了核对。

**主要结论：**

- **真实 ETF 区间（2010–2026）**：没有统计上显著的证据表明这条规则有择时价值。我们把规则和以下基准比较：直接持有 SPY/QQQ、平均仓位相同的固定组合（只用当时已知的信息确定仓位）、30% 波动率目标策略。日频路径 bootstrap（在重抽样路径上按完全相同的定义重跑所有方案）中，所有 Sharpe 和 Calmar 差异都不显著（中心化双侧 p ≥ 0.35）；对 45 组参数做多重检验（SPA）后，按相同波动率比较，p 值都不低于 0.77。
- **和直接持有 SPY/QQQ 相比**：每年多赚 7–11 个百分点，但最大回撤深 20–27 个百分点，Sharpe 和 Calmar 都更低。多出来的收益来自杠杆，而不是择时。
- **滚动前推检验**（前 5 年选参数、下一年检验）：对 SPXL 没有带来改进。
- **包含合成数据的 1999–2026 年假设性历史**：SPXL 版本明显占优，原因是 2000–02 年和 2007–09 年大部分时间都在空仓；TQQQ 版本则不如波动率目标策略。在逐一剔除危机并重新模拟交易的检验中，把几次大危机连同之后的恢复期全部剔除后，这些优势都不再成立。

运行：`pip install -r requirements.txt` → 把四个 CSV 放进 `data/raw/`（复现压缩包里已附带）→ `./run_all.sh`。
